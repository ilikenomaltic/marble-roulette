# Marble Roulette

Based on [lazygyu/roulette](https://github.com/lazygyu/roulette) (MIT License, © 2023 LazyGyu).

## Added Features
- Group assignment mode (2/3/4 per group) based on marble arrival order
- Teacher settings panel (type `teacher` on keyboard) — configure conflict pairs that should not be in the same group
- Conflict pairs are handled via physics impulse during the race
- Auto-fill names (1번~N번)
